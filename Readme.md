# Nigerian Graduate Employment & Salary Analysis

## Overview

This project analyses a dataset of Nigerian graduates to explore patterns
between demographic, academic, economic, and employment factors.

The dataset contains information about graduates including:

- Age
- Gender
- State of Origin
- Region
- Urban/Rural background
- Field of Study
- University Type
- GPA/Class of Degree
- Postgraduate status
- Years Since Graduation
- Employment Status
- Salary Level
- Net Monthly Salary

## Objectives

The main objectives of this project are to:

- Explore the characteristics of the graduates in the dataset
- Analyse employment outcomes
- Investigate salary distributions
- Explore relationships between education and employment outcomes
- Examine relationships between years since graduation and salary
- Identify interesting patterns in the data

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset was obtained from Kaggle.

Each row represents a graduate and contains demographic,
academic, economic, and employment information.

## Analysis

The analysis will include:

1. Data inspection
2. Data cleaning
3. Exploratory data analysis
4. Statistical analysis
5. Data visualisation
6. Interpretation of findings
